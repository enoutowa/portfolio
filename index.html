制作依頼・専用チャット

承認された依頼者ごとに専用ページを用意し、 メッセージ送信、画像添付、管理者からの返信ができる やり取り機能を実装しています。 依頼者ごとにURLを分け、他の依頼者とのやり取りが 表示されない構成にしています。

データ保存

静的ページだけでは保持できない情報を扱うため、 データベースを利用しています。 コメント、応援数、制作依頼、 チャットメッセージ、添付画像情報などを 保存できる仕組みを構築しています。

公開・管理

WebサイトのファイルをGitHubで管理し、 GitHub Pagesを利用して公開しています。 更新履歴を残しながら運用し、 管理画面からサイト内容を更新するための GitHub App連携も導入しています。

SEO・検索エンジン対応

ページタイトル、説明文、構造化データ、 Google Search Console、sitemap.xmlなどを設定しています。 BLOGや歌詞コンテンツの追加・削除に合わせて、 sitemapも自動更新される仕組みにしています。

サイト運用に必要なページ

制作依頼を継続して受け付けられるよう、 利用規約、お問い合わせ、 プライバシーポリシーも整備しています。 制作依頼時の支払い・修正・キャンセルや、 個人情報の取り扱いについても掲載しています。
